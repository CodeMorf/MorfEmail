El vídeo dura aproximadamente 41 segundos y fue revisado tomando una imagen de cada segundo. No debe publicarse tal como está: empieza mostrando WhatsApp Web con una conversación personal y mantiene visible la barra de Real Screen Recorder durante toda la grabación. Además, muestra avisos de Windows apilados, datos de prueba y un flujo que no llega a demostrar una programación automática completada.

La grabación sirve como evidencia de una sesión de prueba, pero no como vídeo comercial. Antes de subirla a CodeCanyon o usarla como demo pública hay que grabarla de nuevo en un entorno limpio.

## Fallos confirmados

1. **Privacidad:** WhatsApp Web y contenido personal aparecen en los primeros segundos.
2. **Captura no limpia:** la barra "Real Screen Recorder está compartiendo tu pantalla", el escritorio y una terminal aparecen durante la demo.
3. **Estado incorrecto durante la verificación:** el texto "Completado" aparece cuando la barra está en 20 %, 60 % y 80 %. Debe cambiarse a "En progreso" hasta 5/5.
4. **Notificaciones repetidas:** los avisos de ventanas y, más adelante, los avisos de eliminación se apilan y tapan parte de la aplicación.
5. **Datos de prueba:** el verificador muestra cinco direcciones de ejemplo, incluido un dominio inexistente. No deben presentarse como contactos reales.
6. **Métricas fáciles de malinterpretar:** 1.554 leads, 32 emails, 187 teléfonos y 0 verificados no prueban que todos los leads tengan datos completos o validados.
7. **Vídeo mal identificado:** el archivo termina en mp4, pero su contenedor detectado es Matroska/WebM con vídeo VP8 y sin duración declarada en metadatos. Para distribución comercial debe exportarse como MP4 H.264 con audio AAC o sin audio.

## Pendientes que el vídeo no permite confirmar

- Pulsar "Programar" con la lista de destino vacía y comprobar que la aplicación bloquee el guardado con un mensaje claro.
- Ejecutar una búsqueda real completa y verificar que país, ciudad, zona, empresa, teléfono, email y URL correspondan entre sí.
- Esperar a 5/5 en el verificador y mostrar el detalle final de cada dirección.
- Confirmar que eliminar leads actualiza resultados, dashboard, historial y listas sin duplicar eventos.
- Repetir el flujo con licencia activa y con licencia vencida, incluyendo el bloqueo del panel.

## Cómo grabar una demo comercial correcta

1. Abrir directamente MorfEmail en una cuenta de demostración sin datos personales.
2. Cerrar WhatsApp, terminales, carpetas y cualquier ventana ajena al producto.
3. Detener u ocultar el grabador antes de capturar la pantalla; no incluir la barra de compartir de Windows.
4. No mostrar la pantalla de configuración de API keys en un vídeo público.
5. Usar datos ficticios claramente marcados como "Demo" o datos públicos previamente revisados.
6. Esperar a que cada operación termine antes de cambiar de pantalla.
7. No borrar leads durante la presentación; si se necesita demostrarlo, usar una base de datos de demo y explicar la acción.
8. En el programador, seleccionar una lista, pulsar "Programar", mostrar la confirmación y después mostrar la tarjeta de la tarea creada.
9. Exportar a MP4 H.264 y reproducir el archivo final completo antes de subirlo.
